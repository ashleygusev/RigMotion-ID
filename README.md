RigMotion

A lightweight 2D skeletal animation editor for mobile and desktop.

RigMotion is an experimental, browser-based animation editor focused on image-based character animation and a simple frame-by-frame workflow.

Features

- Frame-by-frame animation timeline
- Add and delete animation frames
- Onion skinning
- Import PNG, JPEG, and WebP images
- Position, rotation, and scale controls
- Object layers
- Undo and redo
- Local project saving
- Mobile-friendly interface

Getting Started

1. Download "index.html" from this repository.
2. Open the file in a modern web browser.
3. Create a new project.
4. Import your character's body-part images.
5. Arrange your images on the canvas.
6. Add frames and animate your character.
7. Use onion skinning to compare neighboring frames.

Project Status

RigMotion is an experimental project under active development.

Features may change, and bugs may occur. Please test the application with copies of important projects and report any issues you encounter.
